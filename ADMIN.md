# FABULA ONE — инструкция администратора

## Админка есть
- URL: `https://fabulaone.ru/admin` (локально: `http://localhost:3000/admin`)
- Это **Payload CMS** внутри того же Next.js-проекта
- При **первом** заходе создаёте аккаунт администратора сами
- Дальше: продукты, заказы, PERSONAL, партнёры, промокоды, страницы, медиа

## Продукты
1. Медиа → обложка и демо (в Object Storage при наличии YOS_*)
2. Продукт → тексты, цена, связи с медиа
3. `fullAudioKey` = путь полного файла в бакете (`audio/slug.m4a`)
4. Опубликован = да

## PERSONAL
Оплата → анкета → вы ставите файл (`audioKey`) и статус **Готово** → письмо клиенту

## Возврат
В заказе смените статус на **Возвращён** — уйдёт запрос в ЮKassa, партнёрское начисление аннулируется.

## Партнёры / промо
Ссылка `/?ref=КОД`, процент индивидуальный, выплаты вручную. Промокоды — в своей коллекции.

## Юр. страницы
Slug: `offer`, `privacy`, `consent`, `payment-refund`, `contacts`

## Seed (демо-контент)
```bash
npm run db:dev   # Postgres+Redis (нужен Docker)
npm run seed     # 6 фабул-заглушек + юр. страницы + анкета
```
